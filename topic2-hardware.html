§ 01

Core Components

⚠ Exam Alert — 2025 Q2a (5 marks) "Describe the function of: CPU, RAM, Storage device, Input device" — straight 5 marks. One sentence per component is enough but it must be precise.
⚙️
Processing
CPU
The brain of the computer. Fetches, decodes, and executes instructions. Contains the ALU (arithmetic/logic), Control Unit, and Registers. Clock speed (GHz) and number of cores determine performance.
🧮
Memory
RAM
Temporary working memory. Stores programs and data currently in use by the CPU. Volatile — contents lost when power is off. More RAM = faster multitasking. Measured in GB.
💾
Storage
Storage Device
Permanently stores data even when the computer is off (non-volatile). Examples: HDD, SSD, USB flash drive, optical disc. Measured in GB/TB.
⌨️
Input
Input Device
Allows users to send data INTO the computer. Examples: keyboard, mouse, scanner, microphone, webcam, touchscreen, barcode scanner.
🖥️
Output
Output Device
Delivers processed results FROM the computer to the user. Examples: monitor, printer, speakers, projector, headphones.
🔌
Foundation
Motherboard
The backbone of the computer — a printed circuit board (PCB) that connects all components. Contains CPU socket, RAM slots, expansion slots, BIOS chip, SATA connectors, and chipset.

§ 02

CPU Performance

Exam Alert — 2025 Q3c (6 marks) "Explain how clock speed and number of cores affect system performance" — this bridges the hardware and CPU topics. Know both clearly.
⏱️
Clock Speed
Measured in GHz (gigahertz). Represents how many cycles per second the CPU executes. A 3.5GHz CPU performs 3.5 billion cycles per second. Higher clock speed = faster processing of each instruction.
🔲
CPU Cores
A core is an independent processing unit inside the CPU. Dual-core = 2 cores, Quad-core = 4 cores. More cores = better multitasking. Each core can handle a separate task simultaneously.
📦
Cache Memory
Ultra-fast memory built into the CPU. L1 (fastest, smallest), L2, L3 (slowest, largest). Stores recently used data so the CPU doesn't have to fetch from slower RAM repeatedly.
Exam Answer Template — 2025 Q3c "Clock speed determines how fast the CPU executes individual instructions — a higher GHz means more instructions per second. The number of cores determines how many tasks can be processed simultaneously — a quad-core CPU can handle 4 tasks at once, improving multitasking performance significantly."

§ 03

Storage Devices

⚠ Exam Alert — 2025 Q2b (4 marks) "Differentiate between HDD and SSD" — this is a guaranteed 4 marks. Know at least 4 differences.
FeatureHDD (Hard Disk Drive)SSD (Solid State Drive)
TechnologyMagnetic spinning plattersFlash memory (no moving parts)
SpeedSlower (mechanical read/write)Much faster (electronic)
DurabilityFragile — sensitive to shocks/dropsMore durable, resistant to shock
NoiseMakes noise (spinning disk)Silent operation
Power useUses more power, generates heatEnergy efficient, less heat
CostCheaper per GBMore expensive per GB
LifespanMechanical wear over timeLimited write cycles but generally longer
SizeBulkier (3.5" or 2.5")Compact (2.5", M.2, or PCIe card)

Other Storage Types

💿
Optical Storage
Uses lasers to read/write. CD (700MB), DVD (4.7–8.5GB), Blu-ray (25–50GB). Can be read-only, write-once, or re-writable.
🔌
Flash / USB Drive
Portable flash memory storage. Non-volatile, no moving parts. Connects via USB. Common sizes: 8GB–1TB.
📼
Magnetic Tape
Sequential access storage. Slow but very cheap for large archives. Used for backups and long-term data storage in enterprise environments.
Volatile vs Non-Volatile — Exam Q (2025 Q3d) Volatile: loses data when power is off. Examples: RAM, Cache. Non-volatile: retains data without power. Examples: HDD, SSD, USB flash drive, ROM, optical disc.

§ 04

Computer Ports

Exam Alert — 2025 Q2c (4 marks) "Explain what is meant by computer ports, giving two examples."
Definition A port is a physical connection point (socket/interface) on a computer that allows external devices to be connected. Ports enable communication between the computer and peripherals.
USB
Universal Serial Bus
Most common port. Used for keyboards, mice, flash drives, phones. USB-A, USB-C, USB 3.0.
HDMI
High-Definition Multimedia Interface
Transmits both audio and video digitally. Used to connect monitors, TVs, projectors.
VGA
Video Graphics Array
Older analog video port. Still found on many projectors and older monitors. 15-pin connector.
Ethernet
RJ-45 Network Port
Wired network connection. Connects computer to router/switch for internet or LAN access.
Audio
3.5mm Jack
For headphones and microphones. Green = output (speakers), Pink = input (mic), Blue = line-in.
SATA
Serial ATA
Internal port on motherboard for connecting HDD/SSD storage drives. SATA 3 = 6Gbps.
DisplayPort
DP / Mini DP
High-performance digital display interface. Supports high refresh rates and multiple monitors.
PS/2
Personal System/2
Older port for keyboards (purple) and mice (green). Largely replaced by USB.

§ 06

Past Paper Questions

// Think before you click. Answer in your head first.

Model Answer
  • CPU — The Central Processing Unit is the brain of the computer. It fetches, decodes, and executes instructions. It contains the Control Unit, ALU, and registers.
  • RAM — Random Access Memory is the computer's temporary working memory. It stores programs and data currently in use by the CPU. It is volatile — data is lost when power is off.
  • Storage device — Permanently stores data even when the computer is powered off (non-volatile). Examples include HDD, SSD, and USB flash drives.
  • Input device — Hardware that allows users to enter data into the computer. Examples: keyboard (types text), mouse (controls pointer), scanner (digitizes documents).
Model Answer — need at least 4 differences
  • Technology: HDD uses magnetic spinning platters to store data; SSD uses flash memory chips with no moving parts.
  • Speed: SSDs are significantly faster at reading and writing data than HDDs due to electronic rather than mechanical operation.
  • Durability: HDDs are fragile and sensitive to physical shock due to moving parts; SSDs are more durable.
  • Noise: HDDs produce mechanical noise; SSDs operate silently.
  • Cost: HDDs are cheaper per GB; SSDs cost more per GB but prices are falling.
  • Power: SSDs consume less power and generate less heat than HDDs.
Model Answer
  • A computer port is a physical interface or connection point on a computer that enables external devices (peripherals) to be attached and communicate with the computer system.
  • USB (Universal Serial Bus) — The most common port, used to connect keyboards, mice, flash drives, smartphones, and other peripherals. Supports data transfer and power delivery.
  • HDMI (High-Definition Multimedia Interface) — Transmits both high-definition audio and video signals digitally. Used to connect monitors, televisions, and projectors to a computer.
Model Answer (1 mark each)
  • Input — Keyboard: Allows the user to type text and commands into the computer.
  • Input — Mouse: A pointing device that controls the cursor on screen and allows selection of items.
  • Output — Monitor: Displays the visual output (text, images, video) processed by the computer.
  • Output — Printer: Produces a physical (hard copy) of documents and images on paper.
Model Answer
  • Clock Speed: Measured in GHz, clock speed determines how many instruction cycles the CPU executes per second. A higher clock speed means the CPU processes individual instructions faster, improving performance for tasks that are single-threaded.
  • Number of Cores: Each core is an independent processing unit. Multiple cores allow the CPU to process several tasks simultaneously (parallel processing). A quad-core CPU can handle 4 threads at once, improving performance for multitasking and multi-threaded applications.
  • Combined effect: A CPU with both high clock speed AND multiple cores delivers the best overall performance — high clock speed handles fast single tasks while multiple cores improve simultaneous processing.
Model Answer (2 marks each)
  • Input — Keyboard: Advantage: Allows fast, accurate text input and supports shortcuts that speed up workflow.
  • Input — Scanner: Advantage: Converts physical documents into digital format, enabling easy storage and sharing.
  • Output — Monitor: Advantage: Provides immediate visual feedback, allowing users to interact with the computer in real time.
  • Output — Printer: Advantage: Produces permanent, portable hard copies of digital documents for sharing or filing.
