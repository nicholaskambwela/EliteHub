§ 01

The Memory Hierarchy

The Golden Rule The closer memory is to the CPU, the faster it is — but also the smaller and more expensive it gets. The further away, the larger and cheaper — but slower. This trade-off is the memory hierarchy.
CPU Registers
Inside the CPU itself. Holds data actively being processed right now. PC, MAR, MBR, ACC, IR.
Speed: Fastest Size: Bytes Cost: Highest
Cache Memory
SRAM built into/near CPU. Stores recently used data so CPU doesn't repeatedly fetch from RAM. L1 → L2 → L3.
Speed: Very Fast Size: KB–MB Cost: High
RAM (Main Memory)
Temporary working memory. Holds programs and data currently in use. Volatile — lost on power off. DRAM-based.
Speed: Fast Size: GB Cost: Medium
Secondary Storage
Permanent non-volatile storage. HDD, SSD, USB drives. Data persists without power. Loaded into RAM when needed.
Speed: Slower Size: TB Cost: Low
Offline/Archival Storage
Magnetic tape, optical discs. Very cheap per GB. Used for backups and long-term archiving. Accessed rarely.
Speed: Slowest Size: TB+ Cost: Lowest

§ 02

RAM — Random Access Memory

⚠ Exam Alert — 2025 Q1b · 2015 Q3c · CIT3100 "Explain the difference between RAM and ROM" (4 marks), "Compare DRAM and SRAM" — these appear repeatedly. Know RAM cold.
Definition RAM (Random Access Memory) is the computer's temporary working memory. It stores programs and data currently being used by the CPU. It is volatile — all data is lost when the computer is switched off. More RAM = better multitasking performance.

§ 03

ROM — Read-Only Memory

Definition ROM (Read-Only Memory) is non-volatile memory that retains its data even when the computer is switched off. It is pre-programmed by the manufacturer. The BIOS/UEFI firmware that starts your computer is stored in ROM.
⚠ Exam Alert — 2025 Q1b · 2015 Q3d · CIT3100 "Differentiate ROM and RAM" — 4 marks. "Discuss PROM and EPROM ROM variations" — 2015 exam. Know all 4 ROM types.
ROM
Read-Only Memory
Factory-programmed. Cannot be changed by the user at all. Contains permanent firmware like the original BIOS. Data survives without power.
Not writable
PROM
Programmable ROM
Can be written to ONCE by the user using a special PROM programmer device. After programming, it behaves like regular ROM — cannot be changed again.
Write once only
EPROM
Erasable PROM
Can be erased by exposing it to strong ultraviolet (UV) light for 15–20 minutes, then reprogrammed. Has a small quartz window on the chip for UV exposure.
Erasable with UV light
EEPROM
Electrically Erasable PROM
Can be erased and reprogrammed electrically — no UV needed. Modern BIOS chips use EEPROM. Flash memory (USB drives, SSDs) is a type of EEPROM.
Electrically erasable

§ 04

Exam Answer Template — 2025 Q3d "Volatile memory loses its data when power is switched off. Examples include RAM and CPU cache. Non-volatile memory retains data without power. Examples include ROM, HDD, SSD, and USB flash drives. Volatile memory is used for temporary working data while the computer runs; non-volatile is used for permanent storage of the operating system, applications, and user files."

§ 05

Secondary Storage

Key Point Secondary storage is non-volatile and holds data permanently. When you open a program, the OS copies it from secondary storage into RAM. When you save a file, it goes back to secondary storage.

Storage Types by Technology

TechnologyExamplesHow it worksKey characteristics
MagneticHDD, Tape driveMagnetised/demagnetised areas on spinning platters or tapeCheap per GB, slow, moving parts, fragile
Solid StateSSD, USB flash drive, SD cardElectrical charges in NAND flash memory cellsFast, durable, silent, no moving parts, pricier
OpticalCD, DVD, Blu-rayLaser reads/writes pits and lands on disc surfacePortable, cheap, easily scratched, lower capacity
HybridSSHD (Solid State Hybrid)Combines HDD platters + small SSD flash cacheFaster than HDD, cheaper than SSD

Storage Capacity Reference

Cache Memory — Exam Extra (2025 Q3b, CIT3100) Cache sits between CPU and RAM. L1 (fastest, ~32KB, inside CPU core), L2 (~256KB, inside CPU), L3 (~8MB+, shared across cores). When CPU needs data it checks L1 first, then L2, L3, then RAM. The further it has to go, the slower the access.

§ 07

Past Paper Questions

// Think before you click. Answer in your head first.

Model Answer
  • RAM (Random Access Memory) is volatile temporary memory — it stores programs and data currently in use by the CPU, but all data is lost when the computer is switched off.
  • ROM (Read-Only Memory) is non-volatile permanent memory — it retains its data without power and contains firmware like the BIOS that is pre-programmed by the manufacturer.
  • Key difference 1: RAM is volatile; ROM is non-volatile.
  • Key difference 2: RAM can be read and written by the CPU; ROM can only be read (normally).
Model Answer
  • Volatile memory loses all stored data when electrical power is removed. It is used for temporary working storage while the computer is running.
  • Examples of volatile: RAM (DRAM, SRAM), CPU Cache, CPU Registers.
  • Non-volatile memory retains its data even without power. It is used for permanent storage of the OS, applications, and user files.
  • Examples of non-volatile: ROM, HDD, SSD, USB flash drive, CD/DVD, magnetic tape.
Model Answer
  • DRAM stores each bit as an electrical charge in a capacitor and must be constantly refreshed. It is slower, cheaper, denser, and used for main memory (RAM sticks).
  • SRAM uses flip-flop circuits to hold bits without refreshing. It is much faster, more expensive, less dense, and used for cache memory (L1, L2, L3).
  • Similarity: Both are volatile — they lose data without power.
  • Summary: DRAM = cheap, slow, large capacity (main memory). SRAM = fast, expensive, small (cache).
Model Answer (2 marks each)
  • PROM (Programmable ROM): Can be programmed once by the user using a special PROM programmer device. Once written, it cannot be changed — it behaves like regular ROM. Used where custom permanent data is needed.
  • EPROM (Erasable PROM): Can be erased by exposing the chip to ultraviolet (UV) light for approximately 15–20 minutes through a quartz window on the chip, then reprogrammed. Allows reuse of the chip unlike PROM.
Model Answer (2 marks each)
  • Volatility: Main memory (RAM) is volatile — data is lost when power is removed. Secondary memory (HDD, SSD) is non-volatile — data is retained permanently.
  • Speed: Main memory is much faster to access than secondary memory. The CPU can access RAM in nanoseconds, while secondary storage takes milliseconds (HDD) or microseconds (SSD).
  • Capacity and cost: Secondary memory has far larger capacity (TBs) at much lower cost per GB. Main memory is smaller (GBs) and more expensive per GB.
Model Answer (1 mark each)
  • Volatile (1): RAM — temporary working memory that loses data on power off.
  • Volatile (2): CPU Cache (SRAM) — fast memory inside/near CPU that loses data without power.
  • Non-volatile (1): HDD — magnetic spinning drive that retains data permanently.
  • Non-volatile (2): SSD — flash memory drive that retains data without power.
