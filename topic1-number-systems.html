§ 01

The Three Number Systems

⚠ Exam Alert — 2015, 2019, 2024, 2025 Number conversions appear in literally every exam paper collected. If you can't convert between Binary, Decimal, and Hex in your sleep, you're leaving marks on the table.
2
Binary
Base-2
Digits: 0, 1
Used internally by ALL computers. Every file, image, and instruction is stored as a sequence of 0s and 1s. Each digit is called a bit. 8 bits = 1 byte.
10
Decimal
Base-10
Digits: 0–9
The number system humans use every day. Each position represents a power of 10 (1s, 10s, 100s, 1000s...). The most intuitive system for people.
16
Hexadecimal
Base-16
Digits: 0–9, A–F
Used in programming, memory addresses, and color codes (#FF5733). A=10, B=11, C=12, D=13, E=14, F=15. 1 hex digit = 4 binary bits.

§ 02

Decimal ↔ Binary

Exam Question — 2024 Q1c "Convert 30₁₀ to binary (show your working)" — 2 marks for the working, 1 for the answer. Always show the division table.
Method: Decimal → Binary (Repeated Division by 2) 2024 Exam Example

Example: Convert 30₁₀ to binary

StepDivide by 2QuotientRemainder (bit)

215 ÷ 271
37 ÷ 231

Read remainders bottom to top →11110₂
Answer 30₁₀ = 11110₂ · Always read the remainders from BOTTOM to TOP (MSB to LSB).
Method: Binary → Decimal (Positional Weights) 2025 & 2019 Exam

Example: Convert 1101101₂ to decimal (2025 Exam Q1a)

1
Write out each bit and its positional weight (powers of 2 from right to left: 2⁰, 2¹, 2², etc.)
Bit position6543210
Bit value1101101
Weight (2ⁿ)6432168421
Contribution643208401
2
Add up all contributions where bit = 1: 64 + 32 + 8 + 4 + 1 = 109
= 109₁₀
Answer 1101101₂ = 109₁₀
Also from 2025 exam — Convert 156₁₀ to binary Try it yourself using the division table method. Answer: 10011100₂ Working: 156÷2=78 r0 → 78÷2=39 r0 → 39÷2=19 r1 → 19÷2=9 r1 → 9÷2=4 r1 → 4÷2=2 r0 → 2÷2=1 r0 → 1÷2=0 r1. Read bottom to top: 10011100.

§ 03

Hexadecimal ↔ Decimal

Exam Question — 2025 Q1a "Convert 3A₁₆ to decimal" — 2 marks. Know your A=10, B=11...F=15.
Method: Hex → Decimal 2025 Exam

Example: Convert 3A₁₆ to decimal

1
Write each hex digit and its positional weight (powers of 16 right to left)
2
3 is in position 1 (16¹ = 16), A is in position 0 (16⁰ = 1). Remember A = 10.
3
Multiply each digit by its weight: (3 × 16) + (10 × 1) = 48 + 10 = 58
= 58₁₀
Answer 3A₁₆ = 58₁₀

Shortcut — Hex ↔ Binary 1 hex digit = exactly 4 binary bits. So 3A₁₆ = 0011 1010₂. Split the hex into digits, convert each to 4-bit binary. This is why programmers love hex — it's compact binary.

Model Answer
  • 1101101₂ to decimal: 1×64 + 1×32 + 0×16 + 1×8 + 1×4 + 0×2 + 1×1 = 64+32+8+4+1 = 109₁₀
  • 156₁₀ to binary: Divide repeatedly by 2 → remainders read bottom to top = 10011100₂
  • 3A₁₆ to decimal: 3×16 + 10×1 = 48+10 = 58₁₀
Model Answer
  • 30₁₀ to binary: 30→15 r0, 15→7 r1, 7→3 r1, 3→1 r1, 1→0 r1. Answer = 11110₂
  • 1011 + 1101 = 11000₂ (carries: 1+1=10, carry the 1)
  • 1101 - 1011 = 0010₂
  • 1001 × 111 = 111111₂ (= 63₁₀, verify: 9×7=63 ✓)
  • 10101 ÷ 11 = 111₂ remainder 0 (= 21÷3=7 ✓)
Model Answer
  • 1011011₂ to decimal: 1×64+0×32+1×16+1×8+0×4+1×2+1×1 = 64+16+8+2+1 = 91₁₀
  • 47.54₁₀ to binary: Integer part 47: divide by 2 → 101111₂. Fractional .54: multiply by 2 repeatedly → .54×2=1.08(1), .08×2=0.16(0), .16×2=0.32(0), .32×2=0.64(0), .64×2=1.28(1)... → 0.10001.... Full answer: 101111.10001₂
Model Answer
  • 107 ÷ 2 = 53 r1
  • 53 ÷ 2 = 26 r1
  • 26 ÷ 2 = 13 r0
  • 13 ÷ 2 = 6 r1
  • 6 ÷ 2 = 3 r0
  • 3 ÷ 2 = 1 r1
  • 1 ÷ 2 = 0 r1
  • Read bottom to top: 1101011. Pad to 8 bits: 01101011₂
Model Answer (2 marks each)
  • Binary (Base-2) — Uses only digits 0 and 1. Computers use binary internally because electronic circuits have two states: on (1) and off (0).
  • Decimal (Base-10) — Uses digits 0–9. The number system used by humans in everyday life. Computers convert to/from decimal for human-readable output.
  • Hexadecimal (Base-16) — Uses digits 0–9 and letters A–F (A=10 to F=15). Used in programming and memory addresses as a compact way to represent binary data (1 hex digit = 4 bits).
